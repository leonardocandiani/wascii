# Boxes & cards

All frames ≤ 26 columns, one border family, zero emoji inside. Copy as-is.

## Rounded frame (house style)

```
╭────────────────────────╮
│ hello, wascii          │
╰────────────────────────╯
```

## Titled box

```
╭────────────────────────╮
│ DEPLOY                 │
├────────────────────────┤
│ status   live          │
│ region   gru1          │
╰────────────────────────╯
```

## Centered banner title

```
╭────────────────────────╮
│      W A S C I I       │
╰────────────────────────╯
```

## Light frame with sections

```
┌────────────────────────┐
│ SUMMARY                │
├────────────────────────┤
│ open     4             │
│ merged   17            │
│ closed   2             │
└────────────────────────┘
```

## Double frame (emphasis)

```
╔════════════════════════╗
║ RELEASE 1.0.0          ║
╚════════════════════════╝
```

## Stat card

```
┌────────────────────────┐
│ REVENUE                │
│                        │
│   R$ 21,480            │
│   ▲ 12% this week      │
└────────────────────────┘
```

## Callout / quote

```
┌────────────────────────┐
│ " ship beats perfect " │
└────────────────────────┘
```

> Tip: the inner field is 24 cells. Pad every row to 24 with spaces so the right
> border always lands in the same column (R3).

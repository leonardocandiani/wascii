# Changelog

All notable changes to this project are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] — 2026-06-02

First public release.

### Added
- `SKILL.md` — the seven rules and the apply loop for Claude agents.
- `reference/characters.md` — safe/unsafe single-cell Unicode palette, with the
  `✓` vs `✔️` width trap.
- `reference/rules.md` — each rule with a worked before/after example.
- `examples/` — boxes, tables, bars & charts, leaderboards, titles & banners.
- `scripts/check-width.py` — CI guard rejecting any bare fenced block over 26
  cells.
- WhatsApp iPhone mockups (`assets/`) generated to showcase real rendering.
